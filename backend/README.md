# AI Finance Controller - Backend Engine

FastAPI-powered Python financial core providing:
- Deterministic 10-step payment reconciliation waterfall
- Root cause heuristic classification
- Autonomous multi-agent coordination
- Native voice interface and tool dispatching
- Audit trail logging and explainability proofs

## Quickstart

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run test suite
PYTHONPATH=. python3 -m unittest discover -s tests -p "test_*.py"

# 3. Start development server
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
