# AI Finance Controller - Frontend Portal

Razorpay-inspired React/TypeScript financial operations console:
- Live reconciliation metrics & variance waterfall
- Settlement batch intelligence & timing tracker
- Exception management queue with root-cause drill-downs
- Forward liquidity & 7-day cash forecast visualization
- Global Ask Vaani Voice Copilot with live waveform animation

## Quickstart

```bash
# 1. Install dependencies
npm install

# 2. Build for production
npm run build

# 3. Start development server
npm run dev
```
